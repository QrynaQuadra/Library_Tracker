# 📚 English Cafe - Kütüphane Otomasyon Sistemi

Bu proje, okullardaki "English Cafe" kütüphaneleri için geliştirilmiş, modern arayüzlü bir kitap takip ve kütüphane yönetim otomasyonudur. Python ve CustomTkinter kullanılarak geliştirilmiştir.

## ✨ Özellikler
- **📊 Dashboard:** Toplam kitap, öğrenci ve ödünçteki kitap sayılarını anlık takip edin.
- **🔄 Ödünç & İade:** Kitap numarası ve öğrenci bilgileriyle hızlı işlem yapın.
- **📚 Kitap Yönetimi:** Kitap listeleme, yeni kitap ekleme ve sağ tık menüsü ile kitap silme.
- **🎓 Öğrenci Profilleri:** Öğrencilerin okuma geçmişini görüntüleyin ve ceza puanı sistemini yönetin.
- **🐧 Linux Uyumlu:** Linux ortamlarında (Ubuntu/Kubuntu) sorunsuz çalışan özel pencere yönetimi.

## 🛠️ Kullanılan Teknolojiler
- **Dil:** Python 3.12+
- **Arayüz:** CustomTkinter (Modern GUI)
- **Veritabanı:** SQLite3
- **Versiyon Kontrol:** Git & GitHub
